German Mediathek HQ LoRA × 7 emotions — using the manual's own recipes

208 clips, 4 candidates per cell, none discarded. Four arms per emotion and language, so the Mediathek adapter's contribution can actually be isolated.
Why this replaces the first version of this grid. The earlier page used prompts I wrote myself, a flat 0.5 merge for every emotion, and one sampling setting throughout. The manual has a measured, evolved recipe per emotion — and the first grid matched it on dose for 2 of 6 emotions and on prompt and sampling for none.

This version parses md/emotions/<Emotion>.md and uses exactly what is written there, so the recipe has a single home and cannot drift.

Read the duration table before you read anything else. The prompt-only arm sits at 4–10 s in both languages, which is natural for these lines. Adding the Mediathek adapter blows English up — 25.6 s for joy and neutral, 15.9 s for fear — while German stays at 3.8–5.3 s. Adding the emotion adapter on top pushes English further still (amusement 25.6 s, sadness 24.7 s).

This is the same asymmetry the first grid showed, now with a clean baseline proving it is the adapter and not the prompt: the identical prompt without adapters produces 4–10 s. The Mediathek adapter is a German adapter. On English it does not merely colour the delivery, it destroys the pacing. German + both adapters is the configuration to use; German anger and fear stay at 3.8–4.0 s, i.e. unaffected.
